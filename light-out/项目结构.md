## 项目结构:

由于功能模块极多（课程、作业、互评、AI引擎、社区、四六级等），**拆分为多模块项目**。

```
learning-platform/
├── pom.xml (父POM，统一依赖版本)
├── README.md
├── .gitignore
├── docs/                      # 文档目录
│   ├── 功能整合文档.md
│   ├── 数据库设计.md
│   └── API文档/
├── lp-common/                 # 公共模块（工具类、异常、统一响应、JWT等）
├── lp-auth/                   # 认证授权（五级权限体系）
├── lp-course/                 # 课程管理（章节、资源、选课）
├── lp-assessment/             # 任务考核（题库、试卷、成绩、防作弊）
├── lp-peer-review/            # 互评系统
├── lp-learning/               # 学习体验（进度、断点续学、视频管控）
├── lp-community/              # 社区交流（讨论、资源共享）
├── lp-ai-engine/              # AI笔记引擎（核心差异化，独立微服务）
├── lp-self-study/             # 自主学习（错题本、学习报告）
├── lp-cet/                    # 四六级专项 
├── lp-message/                # 消息通知（群聊、私信、待办）
├── lp-admin/                  # 系统管理（数据大屏、模块管理、AI配置）
└── lp-starter/                # 启动入口（聚合所有模块）
```





# Git提交:

**主干开发 + 功能分支**,做完新功能并且调试完毕没有问题后，开一个新分支提交仓库.

### <u>尽量避免强制推送！</u>



## 服务器与中间件配置

生产服务器地址、账号和密码不记录在 Git 仓库中。后端通过服务器上的
`/home/ubuntu/.learning-platform.env` 注入以下变量，文件只允许部署用户读取：

- `SPRING_DATASOURCE_URL`
- `SPRING_DATASOURCE_USERNAME`
- `SPRING_DATASOURCE_PASSWORD`
- `SPRING_DATA_REDIS_HOST`
- `SPRING_DATA_REDIS_PORT`
- `SPRING_DATA_REDIS_PASSWORD`
- `SPRING_RABBITMQ_HOST`
- `SPRING_RABBITMQ_PORT`
- `SPRING_RABBITMQ_USERNAME`
- `SPRING_RABBITMQ_PASSWORD`
- `JWT_SECRET`

端口约定：后端 `8080`，MySQL `3306`，Redis `6379`，RabbitMQ 服务 `5672`，管理控制台 `15672`。
