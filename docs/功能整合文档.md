## 平台定位与出发点

大学的学习本质是自主化的。伴随 AI 与网络发展，学生自学为主体的特征愈发明显。学习平台不应只是"视频仓库 + 成绩系统"，而应成为学生主动使用、愿意使用的工具。

当下学习通、MOOC 平台虽有高质量资源，但真实观看人数有限，同学们更倾向去 B 站等平台自学——资源本身已不是第一竞争力。

因此，本平台定位为：**集教学管理、资源迭代、社区交流、自主学习、专项提升于一体的综合性学习建设平台**，兼顾教师教学管理效率、学生课堂学习需求与课外自主提升需求。

## 十、AI 智能笔记引擎（NotebookLM 核心能力整合）

适用角色：学生（主）、教师（备课 / 出题）、管理员（模型与资源配置）

本模块是平台差异化竞争的核心引擎，将 Google NotebookLM "链接即知识" 的交互范式完整引入，并针对高校教学场景进行深度定制。

### 10.1 核心理念

传统学习平台的内容消费路径是 "找资源 → 看完 → 自己整理"，大量时间花在了"看"上，而非"理解"上。

AI 智能笔记引擎将路径缩短为："丢链接 / 传文件 → AI 秒级解析 → 对话式深挖 → 一键生成笔记/导图/测验"。

用户不再需要从头到尾看完一个 90 分钟的视频才能提取关键信息——AI 代替用户完成"阅读"，用户专注于"思考和提问"。

### 10.2 数据源接入

| 数据源类型 | 接入方式 | 说明 |
|-----------|---------|------|
| 平台内视频 | 自动关联 | 直接引用课程章节中的视频资源，自动获取转录文本与元数据 |
| YouTube / B 站链接 | 粘贴链接 | 通过平台 API 或自动转录提取视频内容，生成结构化笔记 |
| PDF / Word / PPT | 上传文件 | 支持拖拽上传，AI 自动解析文本、表格、图表 |
| 网页链接 | 粘贴 URL | 自动抓取网页正文内容，过滤广告等噪音信息 |
| 学术论文（DOI） | 粘贴 DOI | 自动获取论文摘要、正文、参考文献 |
| 音频文件 | 上传文件 | 支持 MP3 / WAV 等格式，自动转录为文字后进入笔记体系 |
| 多源聚合 | 同一笔记本内添加多个来源 | AI 跨来源综合分析，支持"对比这两篇论文""这段视频和这个文档有哪些观点冲突"等跨文档提问 |

### 10.3 AI 笔记生成能力

| 输出类型 | 说明 |
|---------|------|
| 结构化摘要 | 自动提取核心论点、关键概念、重要数据，按逻辑层级组织 |
| 时间轴索引 | 对视频 / 音频来源，生成带时间戳的关键节点索引，点击即可跳转 |
| 关键术语表 | 自动识别专业术语，生成术语解释卡片 |
| FAQ 自动生成 | 基于内容自动生成常见问题及答案，覆盖重点与易混淆点 |
| 思维导图 | 将内容结构化为可交互的思维导图，支持展开 / 收缩节点 |
| 闪卡（Flashcards） | 自动生成 Anki 风格的记忆闪卡，用于间隔重复复习 |
| 音频概述（Podcast Mode） | 参考 NotebookLM 的 Audio Overview 功能，将笔记转化为一段 5–10 分钟的双人对话式音频概述，学生可在通勤、运动时收听，将碎片时间转化为学习时间 |

### 10.4 对话式深度学习

| 能力 | 说明 |
|------|------|
| 引用式回答 | AI 的每次回答均标注来源——文本来源引用段落，视频来源引用时间戳，确保可溯源 |
| 追问与深挖 | 学生可就回答继续追问，AI 记住上下文，逐层深入 |
| "帮我出题" | 教师 / 学生可一键让 AI 基于当前笔记内容生成测验题，直接导入题库（见 3.2）或自测 |
| "给我讲明白" | 学生选中任意概念或段落，点击后 AI 用更通俗的方式重新解释，可结合类比、举例 |
| 多语言支持 | 外文资料可要求 AI 用中文回答；中文资料也可要求英文摘要，助力学术英语能力提升 |

### 10.5 笔记管理与协作

| 子模块 | 功能说明 | 角色 |
|--------|---------|------|
| 笔记本创建 | 每个笔记本对应一个学习主题，可添加多个数据源 | 全部用户 |
| 笔记编辑 | AI 生成的笔记可手动编辑、批注、高亮，人机协同完善 | 全部用户 |
| 版本管理 | 笔记保留历史版本，可回溯对比 | 全部用户 |
| 分享与协作 | 笔记可设为公开 / 仅课程内可见 / 私有；公开笔记可被他人 fork 并二次编辑 | 全部用户 |
| 教师备课 | 教师可将多份教材、论文、视频导入笔记本，快速生成课程讲义框架和教案 | 教师 |
| 笔记 → 题库 | 教师可将 AI 生成的测验题一键批量导入课程题库（关联 3.2） | 教师 |
| 笔记 → 课程资源 | 教师可将优质笔记导出为课程章节内容，丰富课程资源 | 教师 |

### 10.6 个人知识图谱

将碎片化的学习行为连接为可感知的知识网络。

| 能力 | 说明 |
|------|------|
| 知识点自动标注 | AI 从所有笔记中提取知识点实体，建立关联关系 |
| 薄弱环节可视化 | 知识图谱中，被频繁提问或标记"未理解"的知识点自动高亮为薄弱区域 |
| 学习路径推荐 | 根据知识图谱分析，推荐下一步应学习的内容，形成个性化学习路径 |
| 复习提醒 | 结合遗忘曲线，对薄弱知识点定时推送复习提醒 |

### 10.7 技术实现参考

| 层级 | 技术方案 |
|------|---------|
| 多模态理解 | 采用大语言模型（如 Gemini 1.5 Pro 级别）作为底座，原生支持文本 / 图像 / 音频 / 视频理解 |
| 视频内容提取 | 优先通过 YouTube / B 站 API 获取字幕与元数据；无字幕时调用 ASR（自动语音识别）模型转录 |
| PDF / 文档解析 | 结合 OCR（光学字符识别）与文档布局分析模型，准确提取表格、公式、图表信息 |
| RAG（检索增强生成） | 用户提问时，先从笔记原文中检索最相关段落，再由模型生成回答，确保回答忠实于原始资料 |
| 向量数据库 | 存储所有笔记内容的向量表示，支撑高效的语义检索与跨文档查询 |
| 音频概述生成 | TTS（文本转语音）+ 对话脚本生成模型，将笔记转化为自然对话音频 |

### 创意 1：节点式编程学习（低代码平台 + 视频节点）

在编程类视频课中插入学习节点——视频播放到节点处自动暂停，弹出在线编程 / 低代码编辑界面，学生完成后提交，系统即时判断正误，通过后自动继续播放视频。实现学一点、练一点、会一点的闭环。

### 创意 2：开源式知识库（Wiki-Syllabus）

允许高分通过的优秀学员或助教，在课程页面下补充最新的文献、前沿争议观点或更优的工具代码。课程内容像维基百科一样持续迭代生长，避免"录完即过时"。

与第十章联动：Wiki-Syllabus 中的新补充资料可一键添加至 AI 笔记引擎，快速生成摘要并与原课程内容进行对比分析。

### 创意 3：难点悬赏榜单（Bounty System）

教师或企业将尚未完美解决的小课题发布在平台上（例如：寻找更优的统计绘图方式）。学习者接单并提供解决方案，获得平台积分或专属认证，实现学以致用。

与第十章联动：接单学生可使用 AI 笔记引擎快速研读相关文献、梳理解题思路，降低"上手门槛"。

## 十三、核心业务流程

### 流程一：开课流

```
教师建课 → 上传资源（或通过 AI 笔记引擎解析外部资源后导入）
→ 设置考核标准（如视频 30% / 作业 40% / 互评 30%）
→ 管理员审核 → 课程上线 → 学生选课/被分配
```

### 流程二：学习流

```
学生进入课程 → 观看视频（防拖拽、断点续学）
→ 遇到疑问唤起 AI 笔记引擎侧边栏即时提问
→ 完成课后测验（测验题可能由 AI 笔记引擎自动生成）
→ 提交作业 → 参与互评
```

### 流程三：结果流

```
系统按权重自动汇总各项得分 → 教师确认成绩
→ 学生查看（可申诉）→ 教师复核修改（全程留痕）→ 导出成绩单（Excel）
```

### 流程四：自主学习流

```
学生浏览课程库 → 选择感兴趣的课程 → 选定学习模式
→ 【AI 笔记引擎模式】粘贴视频/论文链接 → AI 生成结构化笔记
→ 与笔记对话式深挖 → 生成思维导图/闪卡/音频概述
→ 生成学习报告 → 复盘总结
```

### 流程五：AI 笔记引擎使用流

```
学生创建笔记本 → 添加来源（链接 / 上传文件 / 选择平台内资源）
→ AI 自动解析，生成摘要 + 时间轴 + 术语表 + FAQ
→ 学生提问 → AI 引用原文回答 → 学生编辑完善笔记
→ 一键生成思维导图 / 闪卡 / 音频概述
→ 分享至社区 / 导入课程资源
```
